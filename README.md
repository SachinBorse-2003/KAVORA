# Kavora — Premium Creative Content & Growth Agency

A beautifully crafted single-page website for Kavora, built with **React**, **Next.js**, **Tailwind CSS**, and **Framer Motion**.

## Features

✨ **Smooth Animations**
- Letter-by-letter hero text fade-up
- Sparkle twinkling accents
- Scroll-reveal sections with fade + slide animations
- Service card hover lift with underline sweep
- Infinite marquee scroll
- Video thumbnail zoom on hover with pulsing play button

🎨 **Premium Design**
- Executive color scheme: Burgundy, Cognac, Blush, Cream
- Editorial typography: Playfair Display (headings), Inter (body), Dancing Script (signature)
- Sharp corners, minimal aesthetic, luxury vibe
- Mobile-first responsive design

📱 **Sections**
- Sticky Navigation with scroll-triggered styling
- Hero with two CTAs
- Marquee strip with service keywords
- 4-card Services grid (numbered 01–04)
- Video gallery with modal lightbox
- 4-step Process timeline
- Founder story with signature
- 5 Why Kavora pillars
- Full-width CTA band
- Rich footer with links & socials

## Stack

- **Framework**: Next.js 14 (App Router)
- **Styling**: Tailwind CSS 3
- **Animations**: Framer Motion 10
- **Language**: TypeScript
- **Fonts**: Google Fonts (Playfair Display, Inter, Dancing Script)

## Installation

```bash
# Install dependencies
npm install

# Run development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Project Structure

```
src/
├── app/
│   ├── layout.tsx          # Root layout with metadata
│   ├── page.tsx            # Main page
│   └── globals.css         # Global styles & animations
├── components/
│   ├── Navigation.tsx      # Sticky nav with scroll detection
│   ├── Hero.tsx            # Full-screen hero with CTAs
│   ├── Marquee.tsx         # Infinite scrolling keywords
│   ├── Services.tsx        # 4-card service grid
│   ├── OurWork.tsx         # Video gallery with modal
│   ├── Process.tsx         # 4-step timeline
│   ├── Founder.tsx         # Founder story section
│   ├── WhyKavora.tsx       # 5 pillars grid
│   ├── CTABand.tsx         # Full-width CTA section
│   └── Footer.tsx          # Footer with links & socials
```
